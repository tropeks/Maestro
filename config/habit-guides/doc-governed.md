**doc-governed** — este arquivo pertence a uma área com doc canônico (contrato
do produto). O plano desta mudança cita o doc e a seção que a autorizam? Se a
mudança altera o contrato, a emenda ao doc entra no MESMO changeset — doc
divergente do código é fato morto esperando leitor. `maestro docs` mostra o
frescor; `reviewed:` re-atesta sem edição cosmética.
